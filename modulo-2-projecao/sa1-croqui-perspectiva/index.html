Situação de Aprendizagem 1: Croqui e Perspectiva

1.1 O que é Croqui?

O croqui é um desenho rápido, feito à mão livre, com objetivo de expressar ideias, conceitos ou soluções de forma imediata. É uma ferramenta essencial para engenheiros e projetistas.

ℹ️
Diferencial SENAI: O croqui permite comunicar ideias rapidamente antes de criar o desenho técnico formal.

1.2 Perspectiva Isométrica

A perspectiva isométrica é uma forma de representar objetos tridimensionais em duas dimensões, mantendo as proporções reais do objeto. É a forma mais comum de perspectiva usada em desenho técnico.

1.3 Fundamentos do Croqui

Para elaborar um bom croqui, siga estas etapas:

  1. Observação: Analise o objeto ou ideia que deseja representar
  2. Esboço: Faça linhas leves e rápidas para definir as formas básicas
  3. Detalhamento: Adicione detalhes e dimensões aproximadas
  4. Finalização: Reforce as linhas principais e adicione anotações
