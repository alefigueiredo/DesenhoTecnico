Situação de Aprendizagem 3: Desenho de Conjuntos e Elementos de Máquina

3.1 O que é um Desenho de Montagem?

O desenho de montagem mostra como as diversas peças de um mecanismo se encaixam e se relacionam entre si. É essencial para a montagem, manutenção e reparo de máquinas.

3.2 Elementos de Fixação

Os elementos de fixação são usados para unir peças entre si:

  • Parafusos: elementos com roscas externas
  • Porcas: elementos com roscas internas
  • Arruelas: peças planas com furo central
  • Pinos: elementos cilíndricos para alinhamento

3.3 Elementos de Transmissão

Os elementos de transmissão movem e transformam movimentos:

  • Rodas de fricção: transmissão por atrito
  • Rodas de engrenagens: transmissão por engrenagem
  • Polias e correntes: transmissão por correia ou corrente
  • Eixos e mancais: suporte e rotação

3.4 Vista Explodida

A vista explodida mostra as peças separadas, mas mantendo sua posição relativa, facilitando a identificação de cada componente e sua ordem de montagem.

3.5 Lista de Materiais (BOM)

A Lista de Materiais (Bill of Materials) é uma tabela que lista todas as peças que compõem o conjunto, com:

  • Número de peça
  • Descrição
  • Material
  • Quantidade
  • Massa

3.6 Balões de Identificação

Os balões são círculos numerados que se conectam à lista de materiais, identificando cada peça no desenho.
